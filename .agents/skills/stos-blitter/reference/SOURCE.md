# Sources (not redistributed)

The command entries in `commands/` were distilled from the NuBlitter magazine
tutorial (blitter.txt), with the command inventory verified against the token
table inside the actual extension binary (BLITTER.EXG, NuBlitter v1.1 by Asa
Burrows / Architect & Line, 1991, Ambrah repackage 1992). The tutorial text is
not redistributed for copyright reasons; it is widely archived (the exxos
STOS extensions archive carries the BLITTER package, including binaries and
assembly source for a different STORM blitter extension - see `errata.md`
for the distinction). The distilled entries and `errata.md` carry the content.
