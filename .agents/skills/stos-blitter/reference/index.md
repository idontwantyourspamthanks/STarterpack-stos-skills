# Blitter extension command index

NuBlitter v1.1 (Asa Burrows / Architect & Line, 1991; the (c)1992
string belongs to the later Ambrah repackage). Command
inventory verified against the token table inside the extension
binary itself. Requires blitter hardware (STE or Mega ST) and the
extension - see the stos-blitter SKILL.md gate.
