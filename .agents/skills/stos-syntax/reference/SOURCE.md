# Sources (not redistributed)

The command entries in `commands/` and guides in `topics/` were distilled from
the STOS manual and the STOS Compiler user guide (Mandarin/Jawx, 1988) - every
syntax line and code example verified against the original page scans, with
community-verified corrections applied (see `errata.md` and
`errata-response.md`). A supplementary online sprites guide informed the
MOVE X/Y move-string documentation. No verbatim source documents are included
for copyright reasons.
