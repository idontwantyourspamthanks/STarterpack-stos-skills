# Sources (not redistributed)

The command entries in `commands/` were distilled from the official GBP
extension manual (GBP.DOC, shareware, by Neil Halliday / GBP Software,
1992-1995), with the command inventory verified against the V4.7 binary's
token table and the author's COMPILER.S assembly source. The verbatim manual
is not included for copyright reasons; it is freely available from
stoscoders.com (the author's site) and the exxos STOS extensions archive.
The distilled entries and `errata.md` carry the content.
