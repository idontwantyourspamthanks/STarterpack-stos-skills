# Sources (not redistributed)

The command entries in `commands/` were distilled from Asa Burrows' official
STE extension manual (STOS_STE.DOC), supplemented by the STOSSER tutorial
columns it spawned (STE_1.doc, STE_2.doc, STE_DAC.doc, HARD1STE.DOC) and
worked-example docs (STE_EXT2.doc, STEING.doc), all recovered from the
STEEXTv4 package on the exxos STOS extensions archive. The verbatim documents
are not included for copyright reasons; the archive carries them freely. The
distilled entries and `errata.md` carry their content. Note: the BLITTER
extension (BLITTER.EX*) is a SEPARATE extension and is not covered here.
