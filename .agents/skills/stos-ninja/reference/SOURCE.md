# Sources (not redistributed)

The command entries in `commands/` were distilled from the official Ninja
Tracker manual (TRACKER.DOC, V1.05, by L.J. Greenhalgh, 1994/95 - the author
released the extension as PD). The doc is included in the extension's own
archive on the exxos STOS extensions archive (N/ninja.zip); V1.06 exists as
an MSA disk image (N/Ninjav1.06.zip). The distilled entries and `errata.md`
carry the content.
