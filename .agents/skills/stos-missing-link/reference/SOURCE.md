# Sources (not redistributed)

The command entries in `commands/` were distilled from the official Missing
Link documentation (LINK.DOC and UPDATE.DOC, Top Notch, 1993), which ships in
the extension's own Examples/DOCS folder, and from DEANO's community tutorial
(MEGA issue 3). Neither verbatim document is included for copyright reasons;
the tutorial is widely mirrored (STOS Coders, exxosforum). The distilled
entries in `commands/` and the notes in `errata.md` carry their content.
