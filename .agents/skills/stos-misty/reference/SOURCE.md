# Source (not redistributed)

The command entries in `commands/` were distilled from the official Misty
Extension manual v1.7 (Top Notch, 1992). The verbatim manual is not included
for copyright reasons. It is embedded in the Misty shareware package's
INSTALL.PRG, which is widely archived in the Atari community (STOS Coders,
exxosforum, ST Format coverdisk 38). The distilled entries in `commands/` and
the notes in `errata.md` carry its content.
