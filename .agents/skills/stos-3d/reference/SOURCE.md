# Sources (not redistributed)

The command entries in `commands/` were distilled from the official STOS 3D
manual (Voodoo Software / Europress-Mandarin, 1991-92, 110 pages), with the
command inventory verified against the 3D.EXS token table. The verbatim
manual is not included for copyright reasons; it is archived at
stos.atari.st/STOS/3D/ (3DMANUAL.zip), and this project's repo keeps a copy
at extensions/stos-3d/stos_3d_manual.pdf. The distilled entries and
`errata.md` carry the content.
