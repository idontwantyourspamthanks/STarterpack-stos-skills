# Sources (not redistributed)

The command entries in `commands/` were distilled from the official STOS
Maestro manual (Mandarin Software, 1989, by Jon Wheatman of New Dimensions),
a 38-page scanned document hosted by AtariMania (utility entry 43890). The
verbatim manual is not included for copyright reasons; it is freely available
from AtariMania, and this project's repo keeps a copy at
extensions/maestro/stos_maestro_manual.pdf. The distilled entries,
`formats.md` (verified against the bundled SOURCE.S playback engine) and
`errata.md` carry the content.
