# Maestro command index

STOS Maestro (Mandarin Software, 1989, by Jon Wheatman of New
Dimensions). Documented from the official scanned manual (AtariMania).
Sample playback works everywhere; recording needs the Maestro Plus
cartridge - see the stos-maestro SKILL.md gate.

- [Sample formats and playback engine](formats.md)
- [Errata](errata.md)
