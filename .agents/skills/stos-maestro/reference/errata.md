# Maestro KB errata

Transcription notes from distilling the STOS Maestro manual (Mandarin Software, 1989; scanned without a text layer, read from page images), cross-checked against `extensions/maestro/READ.ME` (V1.01) and `extensions/maestro/SOURCE.S`. All example code kept verbatim from the manual.

- SAMRECORD (printed p29): the manual prints "It's important to note that this instruction does store the recording speed as part of the sample. So if you try to play back a sample using the SAMSPEED AUTO instruction, an error will be generated." — internally contradictory, and contradicted by the SAMSPEED AUTO section (printed p23), which states that AUTO errors precisely because samples from other sources such as SAMRECORD lack the encoded speed. Read as "does NOT store"; corrected in the cartridge.md entry and flagged here.
- SAMCOPY (printed p27): the manual prints "SCREENCOPY only works on word boundaries for reasons of speed." SAMCOPY is described in the same breath as "a special version of the standard STOS copy command", so SCREENCOPY is a misprint for the standard STOS COPY command; SCREEN COPY is a different, graphics-only command. Entry text says "the standard copy"; flagged here.
- SAMSPEED AUTO vs SOURCE.S: the manual (printed p23) says AUTO used with a sample lacking the encoded rate generates a syntax error. The engine in SOURCE.S (PLAYSAM) instead falls back to the current rate when the `JON` code is not found ("IF THE CODE IS NOT FOUND ... THEN THE CURRENT SAMPLE RATE IS USED"). The STOS-level command evidently enforces the error itself; both behaviours documented, flagged in the SAMSPEED AUTO entry.
- SAMPLACE examples (printed p28-29): the function appears in listings as `samplace` (e.g. `P=samplace/1000`, `if samplace<49999 then 100`); verified against the page images, since the scan quality makes `samplace` easy to misread as `sample`. The second example's `if samplace=11842 ... :rem Sample 10k long` is kept verbatim (11842 bytes is what the manual prints).
- SAMDIR example (printed p25): the base listing deliberately skips line 30 (and 55) so the suggested additions `30 samloop on` / `55 samloop off` can be inserted; kept as printed.
- READ.ME (V1.01, May 1989) documents two MAESTRO.PRG features not in the manual: right-clicking the record icon enters THRU mode first (RETURN starts recording), and right-clicking the filter icon offers a noise-reduction filter. These concern the sampler program, not the Basic extension commands, so they are noted here rather than in a command entry.
